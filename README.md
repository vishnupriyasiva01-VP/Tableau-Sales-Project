# Tableau Data Visualization & Sales Analysis Portfolio

## Project Overview

This project demonstrates my hands-on practice with Tableau using sales, customer, product, geographic, and order data.

I created and explored a variety of Tableau visualizations to understand business performance, identify trends and patterns, and present data in an interactive and easy-to-understand format.

## Objective

To develop practical Tableau skills by analyzing business data and creating different types of visualizations to identify trends, patterns, relationships, and insights.

## Key Analysis Areas

### Sales Analysis

Analyzed sales performance across different products, categories, regions, states, and time periods.

### Customer Analysis

Explored customer distribution and purchasing behavior across different segments and locations.

### Geographic Analysis

Used maps to visualize sales and customer-related information across countries, states, and cities.

### Product Analysis

Compared products based on sales, quantity, and other available measures to identify performance patterns.

### Time-Based Analysis

Analyzed sales and order trends across different dates and time periods.
